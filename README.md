ai stack
What was added and why?N2-Standard-8 Machine: Switched from E2 to N2 because Onyx and Vespa require AVX2 CPU instructions. E2 instances often run on older hardware that lacks these, causing the "Connection Reset" crashes we saw earlier.Firewall Resource: Added google_compute_firewall. This explicitly opens the ports in Google Cloud so you can actually reach your apps (Onyx on 3000, n8n on 5678, etc.) from your browser.Vespa-Generic Image: Switched the Vespa image to vespa-generic-intel-x86_64. This ensures it runs on a wider variety of Intel chips without crashing.Port Mapping Logic:External (Host): 8081, 8082, 8083. These are for YOU to view the apps.Internal (Docker): All are 8080. This is how the apps talk to each other. I separated the External ports so you don't get "Port already in use" errors.Dozzle (Port 8888): Added this because you asked for it. It lets you view all Docker logs in a nice web interface so you don't have to keep typing docker logs in the terminal.Startup Metadata: The metadata block in main.tf and the curl in setup.sh work together to ensure your VM automatically gets your latest docker-compose.yml from GitHub every time it launches.
